# Music Flashcards

A web-based flashcard application for learning to read music, with MIDI input as the primary interaction method. The application displays a note on a musical staff, and the user has to play the correct note on their MIDI keyboard.

## Features

*   **MIDI Input:** Connect your MIDI device and play the notes directly.
*   **Customizable Practice:** Configure the clef, note range, and accidentals to suit your learning needs.
*   **Simple Interface:** A clean and engaging interface designed to help you focus on learning.

## Tech Stack

*   **Svelte:** A modern JavaScript framework for building user interfaces.
*   **Vite:** A fast and lightweight build tool.
*   **VexFlow:** A library for rendering music notation.
*   **svelte-routing:** A simple routing library for Svelte.
